## ✨ About the Project

**Header Spa & Beauty** is a frontend layout project focused on reproducing a provided design as accurately as possible while applying frontend development best practices.

The project was developed using concepts learned during **Conquer Blocks** training and emphasizes maintainability, responsiveness and clean structure.

During development the following concepts were applied:

✅ Semantic HTML structure  
✅ Styling and architecture with SCSS  
✅ Responsive layout adaptation  
✅ Pixel-perfect design implementation  
✅ SVG asset integration  
✅ Interactive hover states  
✅ Component organization and maintainability  

---

## 🎯 Goal

Develop a static interface that faithfully reproduces the original design while maintaining clean, scalable and responsive frontend architecture.

Special attention was given to:

- Design fidelity
- Semantic structure
- Responsive adaptation
- User interaction states
- SCSS organization

## 🛠️ Run Locally

Clone repository:

```bash
git clone https://github.com/EdgarMadrid/Header_Spa_Beauty.git
```

Enter project:

```bash
cd Header_Spa_Beauty
```

Open:

```bash
index.html
```

Compile SCSS:

```bash
sass --watch scss:css
```
